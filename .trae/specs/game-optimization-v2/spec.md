# 重装机兵原版复刻优化 Spec

## Why
当前游戏在多个方面与原版重装机兵一代存在差异，包括地图连接、敌人分布、道具系统、剧情对话、战斗机制等。需要全面优化以更贴近原版体验。

## What Changes

### 1. 地图系统重构
- 修正所有城镇名称和连接关系，严格遵循原版地图架构
- 为每个城镇添加完整的建筑列表（酒吧、旅馆、人类装备店、战车装备店、明奇小屋、勇士中心等）
- 修复野外区域的敌人分布，按原版设定分配
- 添加原版特有的隐藏地点和事件触发点

### 2. 敌人系统优化
- 重新设计每个区域的敌人列表，匹配原版分布
- 调整BOSS属性（HP、攻击、防御、赏金）匹配原版数据
- 添加原版特有的敌人种类
- 实现区域等级梯度，越往后的区域敌人越强

### 3. 道具/装备系统
- 修正所有道具名称、价格、效果匹配原版
- 实现分店销售：每个城镇的商店只卖特定商品
- 添加原版缺失的道具（如：人类武器、防具的完整系列）
- 战车装备按原版分类（主炮、副炮、引擎、C装置、特殊装备）

### 4. 战斗系统增强
- 实现完整的回合制战斗流程
- 添加战车战斗和步行战斗的差异化体验
- 实现原版特有的战斗指令（攻击、防御、使用道具、撤退）
- 添加战斗动画效果和伤害数字显示

### 5. 剧情/对话系统
- 为每个城镇的NPC添加原版对话内容
- 实现关键剧情事件（红狼登场、战车获得、BOSS战前对话等）
- 添加勇士中心通缉犯名单和赏金系统
- 实现明奇博士复活功能

### 6. 角色系统
- 实现角色装备系统（头、身、手、脚、武器）
- 添加等级提升时的属性成长
- 实现同伴招募和切换功能
- 添加角色状态显示（HP、攻击、防御、装备）

### 7. 战车系统
- 实现战车装备系统（主炮、副炮、引擎、C装置、SE）
- 添加战车装甲值和修复机制
- 实现战车出租店功能
- 添加战车改造店（名称变更、装备更换）

### 8. UI/UX优化
- 重新设计主界面布局，更贴近RPG风格
- 添加地图导航功能
- 优化消息日志显示
- 添加快捷键操作

## Impact
- Affected specs: 全部游戏系统
- Affected code: 
  - `/workspace/src/data/gameData.ts` - 游戏数据全面重构
  - `/workspace/src/types.ts` - 类型定义扩展
  - `/workspace/src/store/useGameStore.ts` - 状态管理逻辑重写
  - `/workspace/src/components/*.tsx` - 所有UI组件优化
  - `/workspace/src/data/dialogs.ts` - 对话数据补充

## ADDED Requirements

### Requirement: 地图系统
The system SHALL provide完整的世界地图，包含原版所有城镇和地点。

#### Scenario: 拉多镇区域
- **WHEN** 玩家从家出发
- **THEN** 可以前往拉多镇，镇内有酒吧、旅馆、装备店、明奇小屋、勇士中心等建筑
- **AND** 从拉多镇南门可前往拉多镇周边，北门需战车

#### Scenario: 完整地图连接
- **WHEN** 玩家探索世界
- **THEN** 地图连接顺序为：拉多镇 → 麦基镇 → 波布镇 → 奥多镇 → 帕特港 → 罗克镇 → 弗里镇 → 伊尔镇 → 无歌村 → 索鲁镇 → 伊甸镇 → 塔镇 → 卡拉镇 → 地狱门 → 诺亚基地

### Requirement: 敌人分布
The system SHALL按区域分配敌人，越靠近最终BOSS的区域敌人越强。

#### Scenario: 区域敌人
- **WHEN** 玩家在拉多镇周边
- **THEN** 遇到的敌人为：巨蚁、杀人虫、仿生蜗牛（低等级）
- **WHEN** 玩家在塔镇周边
- **THEN** 遇到的敌人为：机器人、强化兵、重型坦克（高等级）

### Requirement: 商店系统
The system SHALL实现分店销售，每个城镇的商店卖不同的商品。

#### Scenario: 拉多镇装备店
- **WHEN** 玩家进入拉多镇人类装备店
- **THEN** 可购买：弹弓、皮帽、皮甲、皮靴等初级装备
- **WHEN** 玩家进入伊尔镇装备店
- **THEN** 可购买：机关枪、铁盔、铁甲、铁靴等高级装备

### Requirement: 战斗系统
The system SHALL实现完整的回合制战斗。

#### Scenario: 战斗流程
- **WHEN** 玩家点击攻击
- **THEN** 计算伤害并显示，然后轮到敌人攻击
- **AND** 战斗日志实时显示每次攻击的伤害数值
- **AND** 击败敌人后获得经验和金币奖励

### Requirement: 剧情事件
The system SHALL实现原版关键剧情事件。

#### Scenario: 战狗山洞
- **WHEN** 玩家进入战狗山洞
- **THEN** 触发战狗战斗，红狼出现帮助击败战狗
- **AND** 获得第一辆战车NO.1

#### Scenario: 红狼剧情
- **WHEN** 玩家在酒吧
- **THEN** 可以打听到红狼的情报
- **WHEN** 玩家在大瀑布
- **THEN** 触发红狼与戈麦斯的最终对决

## MODIFIED Requirements

### Requirement: 角色系统
The system SHALL支持角色装备和属性成长。

#### Scenario: 装备系统
- **WHEN** 玩家购买装备
- **THEN** 装备自动穿戴到对应部位
- **AND** 属性实时更新（攻击力、防御力）

#### Scenario: 等级提升
- **WHEN** 玩家获得足够经验
- **THEN** 等级提升，HP、攻击、防御增加
- **AND** 显示升级提示

### Requirement: 战车系统
The system SHALL支持战车装备和装甲修复。

#### Scenario: 战车装备
- **WHEN** 玩家购买战车装备
- **THEN** 装备到当前战车
- **AND** 战车属性实时更新

#### Scenario: 装甲修复
- **WHEN** 玩家在战车装备店
- **THEN** 可以修复战车装甲
- **AND** 花费相应金币
